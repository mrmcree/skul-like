All combat weapon and impact SFX in this directory (katana_slash_1.wav, katana_slash_2.wav,
katana_thrust.wav, hit_light.wav, hit_heavy.wav, spear_thrust.wav, spear_hit.wav,
swing_light.wav, swing_heavy.wav) are mastered from Creative Commons Zero (CC0 1.0
Universal / Public Domain) packs hosted on OpenGameArt.org:

1. Swishes Sound Pack — artisticdude (CC0)
   https://opengameart.org/content/swishes-sound-pack
   Sources used: swish-7.wav, swish-10.wav, swish-11.wav, swish-13.wav

2. RPG Sound Pack — artisticdude (CC0)
   https://opengameart.org/content/rpg-sound-pack
   Sources used: battle/swing2.wav, battle/swing3.wav, battle/sword-unsheathe.wav,
                 battle/sword-unsheathe2.wav

3. 20 Sword Sound Effects (Attacks and Clashes) — StarNinjas (CC0)
   https://opengameart.org/content/20-sword-sound-effects-attacks-and-clashes
   Sources used: sword.3.ogg, sword.5.ogg, sword.6.ogg,
                 sword_clash.1.ogg, sword_clash.5.ogg, sword_clash.8.ogg

4. 3 Melee Sounds — remaxim (CC0)
   https://opengameart.org/content/3-melee-sounds
   Sources used: melee sound.wav, sword sound.wav

Mapping:
- katana_slash_1.wav (+ swing_light.wav): swish-11.wav + sword.6.ogg
- katana_slash_2.wav: swish-13.wav + sword.3.ogg
- katana_thrust.wav (+ swing_heavy.wav): swish-10.wav + swing3.wav + sword.5.ogg + sword-unsheathe2.wav
- hit_light.wav: sword sound.wav + sword_clash.8.ogg
- hit_heavy.wav: melee sound.wav + sword_clash.5.ogg
- spear_thrust.wav: swish-7.wav + swing2.wav + sword-unsheathe.wav
- spear_hit.wav: melee sound.wav + sword_clash.1.ogg

Other files (jump.wav, land.wav, dash.wav, break.wav) are generated by tools/gen_sfx.py.
