# 武士技能动作（Skills.png）

用即梦生成后，保存为 `assets/raw/hero/Skills.png`，然后在 Asset Studio 里选 `hero` 点「处理」
（或 `python tools/process_sprites.py hero`）。处理后游戏会自动用上新动作，不用改代码。

- 比例：16:9
- 参考图：上传 `hero_ref.png`，角色才会和现有动作一致
- 输出两行：第 1 行 `attack_spin`（旋风斩），第 2 行 `attack_rising`（燕返·升），各 6 帧

## 提示词

```
像素艺术精灵图集，2D横版动作游戏角色动作表，年轻女武士，黑色高马尾配红色发带，红色羽织外衣，身后飘动的红色围巾，深色袴裤，右手持武士太刀，16位复古游戏风格，清晰像素颗粒，黑色描边，共2行，每行一个动作，每行6帧：第1行旋风斩6帧：第1帧压低重心、太刀收到身体左后方蓄力，第2帧开始向右横扫、太刀在身前，第3帧身体转成正面、太刀扫到右侧，第4帧身体转成背面、太刀扫到身后，第5帧身体转回右侧、太刀扫回身前完成一整圈，第6帧收势站稳、太刀斜指地面；第2行燕返·升6帧：第1帧深蹲蓄力、太刀低垂在身后下方，第2帧蹬地起跳、太刀从下方开始上挑，第3帧腾空、太刀向右上方挑起到头顶高度，第4帧腾空最高点、手臂完全伸直太刀指向右上方，第5帧空中收刀、双腿收起，第6帧空中下落姿势、太刀横在身前；除旋风斩的第3帧正面和第4帧背面以外，其余帧都是侧视图且身体朝向右侧，同一个角色，每帧角色大小完全一致，腾空的帧也画在格子里同一高度，不需要画出上升的距离，帧与帧、行与行之间留出很大的空隙，武器和飘带不能伸进相邻的帧，不要画刀光特效，纯绿色背景#00FF00，无阴影，无文字，无网格线
```

## 检查要点

- 每行正好 6 个角色，从左到右，不要多也不要少（多了就重新生成）
- 旋风斩中间要有一帧正面、一帧背面，看起来是原地转了一圈
- 燕返·升从蹲下到腾空，刀从下往上挑；腾空帧画在同一高度没关系，游戏里会把人真的往上推
- 太刀没有被切掉、没有伸进旁边的格子；没有刀光
