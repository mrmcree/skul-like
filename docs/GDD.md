# 游戏设计文档（GDD）· 暂名《Skul-like》

> 状态：原型阶段（里程碑 1–2 完成，3 未开始）· 引擎：Godot 4.5 · 最后更新：2026-11-26
> 本文写"游戏是什么、为什么这样设计"。代码怎么组织、怎么跑，见根目录 `CLAUDE.md`。

---

## 1. 一句话概述
一款**和风像素横版动作 Roguelite**：玩家操控一名持太刀的少女武士，在黄昏的神社森林中与骷髅足轻战斗。玩法参考《小骨：英雄杀手》，但**每个角色的动作更精细**（取消、派生、空中连击），走"少而精"路线。

## 2. 设计支柱
| 支柱 | 含义 | 落地方式 |
|---|---|---|
| **手感第一** | 光打木桩就要爽 | 土狼时间、跳跃缓冲、输入缓冲、攻击取消、顿帧、震屏、受击闪白、弹性回弹、音效 |
| **读招与回应** | 敌人出招有预兆，玩家有工具应对 | 敌人蓄力时泛红；冲刺带无敌帧；普攻可打断小怪出招 |
| **少而精** | 换头（换角色）数量不追求多，每个都做精细 | 每个头骨：3 段连招 + 派生动作 + 专属技能 |
| **统一的和风像素美术** | 所有素材出自同一条 AI 生成 + 后处理流程 | 即梦生成 → 工具链像素化 / 对齐 / 质检 |

## 3. 核心循环
```
进入房间 → 清怪（战斗）→ 开门 → 选择下一个房间（奖励不同）→ … → Boss → 结算
   ↑                                                                    │
   └──────────────────── 死亡：回到起点，保留局外成长 ←──────────────────┘
```
- **局内**：拾取头骨（换战斗风格）、道具、金币。
- **局外**：用金币解锁永久成长（规划中）。

## 4. 操作
| 按键 | 动作 |
|---|---|
| A / D、← / → | 移动 |
| K / 空格 | 跳跃（短按低跳、长按高跳；空中可二段跳） |
| S + K | 从单向平台跳下 |
| J | 攻击（3 段连招；空中可攻击，带短暂滞空） |
| L / Shift | 冲刺（地面、空中各一次；**全程无敌**） |
| Esc / HUD「设置」 | 暂停并打开设置 |

## 5. 玩家角色：少女武士（默认头骨）
**外观**：黑色高马尾配红发带、红色羽织、飘动的红围巾、深色袴、太刀。

### 5.1 移动
| 参数 | 当前值 | 说明 |
|---|---|---|
| 跑速 | 110 px/s | 地面加速 1400，摩擦 1600 |
| 跳跃初速 | 270 px/s | 下落时重力 ×1.6，更"干脆" |
| 二段跳 | 1 次 | |
| 土狼时间 / 跳跃缓冲 | 0.10 s / 0.12 s | 容错 |
| 冲刺 | 280 px/s，0.14 s，冷却 0.35 s | 无敌帧；HUD 能量条显示冷却 |

> 所有数值单位是**逻辑像素**（画面逻辑分辨率 480×270），见第 9 节。

### 5.2 战斗：3 段连招
| 段 | 动作 | 伤害 | 前摇 / 判定 / 收招 | 特点 |
|---|---|---|---|---|
| 1 | 横斩 | 8 | 0.07 / 0.09 / 0.16 s | 小幅前冲 |
| 2 | 上挑斩 | 10 | 0.07 / 0.09 / 0.18 s | 判定偏高 |
| 3 | 突刺（重击） | 16 | 0.09 / 0.10 / 0.30 s | 击飞、顿帧 0.13 s、震屏最强 |

- **收招阶段可被跳跃或冲刺取消**；收招中按攻击接下一段。
- 每次攻击都对应 6 帧动画：前摇 → 挥刀 → 收势，挥刀帧与判定框同步出现。
- 空中攻击会让角色短暂滞空（下落速度上限 30），每次落地前可空中攻击的次数有上限。

### 5.3 受伤与死亡
- 血量 100（HUD 显示为 5 颗心，每颗 20 血，支持半心）。
- 受击：击退、0.3 s 硬直、1 s 无敌（角色闪烁）、顿帧和震屏。
- 死亡：跪倒动画，1.5 s 后在出生点复活（原型阶段的临时规则）。

## 6. 敌人
### 6.1 骷髅足轻（普通）
- 血量 60，持长枪。
- AI 状态：**巡逻 → 发现玩家（110 px）→ 追击 → 攻击 → 冷却**；玩家跑出 170 px 外就放弃追击。
- 攻击：**泛红并蹲下蓄力 0.45 s** → 突刺（判定约 38 px 远）→ 收枪，冷却 0.9 s。
- 会被玩家任何一击打断（硬直 0.3 s）。不会走下平台边缘。
- 死亡后倒地、淡出，3 s 后在出生点复活（原型阶段，方便测试）。

### 6.2 蓝甲精英骷髅
同一套美术，用着色器换成蓝色铠甲：
| | 普通 | 精英 |
|---|---|---|
| 血量 | 60 | 140 |
| 蓄力 | 0.45 s | 0.32 s |
| 伤害 | 12 | 18 |
| 霸体 | 无 | **普通攻击打不断它出枪，只有终结技能打断** |

**设计意图**：教会玩家"看到泛红就冲刺穿过去"，以及"留着第 3 段重击来破霸体"。

### 6.3 后续敌人方向（未实现）
- 远程弓箭手骷髅（逼玩家靠近）。
- 飞行骷髅头（考验空中攻击）。
- 换色变体：金甲小头目。
- 第一关 Boss：骷髅武将，2–3 种招式、多阶段。

## 7. 换头系统（里程碑 3，未实现）
- 玩家同时持有 **2 个头骨**，按键切换；切换时释放一次切换技。
- 每个头骨 = 一套 `AttackData` 连招 + 移动参数 + 外观 + 1–2 个技能。
- 首批：**少女武士**（近战均衡，即现在的主角）+ 1 个反差头骨（远程或重击）。
- 代码结构已为此预留：连招是数据（`data/attacks/*.tres`），受击反应组件通用。

## 8. 关卡
### 8.1 第一关：黄昏神社森林
- 960×270 逻辑像素的测试房间，平地，无跳跃平台。
- 视差分层（远 → 近）：远山与夕阳 → 中景杉树林 → 萤火虫 → 后景装饰（鸟居、石灯笼、神社、石阶、栅栏…）→ 游戏层（草地 + 树根截面）→ 前景草丛 → 前景暗色剪影。
- 构图按区域编排：入口小路 → 林间 → 大鸟居（两侧石灯笼对称）→ 遗迹 → 内社（精英守关）。

### 8.2 一局的结构（里程碑 4，未实现）
5–6 个手工设计的房间随机串联，清完开门，最后 Boss。

## 9. 美术方向
- **风格**：16 位复古像素，和风，黄昏冷色调（深青绿、苔藓绿、暮紫）；角色用高饱和红色，从背景中跳出来。
- **分辨率模型**：逻辑分辨率 480×270，按窗口分辨率渲染（默认 1920×1080，即 4 倍）。角色、中景、装饰物使用 **2 倍精度**贴图（缩小一半显示），远景和地面使用原生像素网格。
- **素材来源**：即梦 / 豆包生成 → 工具链处理（抠绿幕或洋红背景、去水印、对齐像素网格、统一调色板、描边、切帧、对齐脚底）→ 自动质检。
- **特效**：刀光为蓝白色统一配色（专门生成的太刀刀光序列）；命中火花、尘土、烟雾来自 pixelfx（MIT）。
- **UI**：头像框、像素爱心、米色能量条、金币计数，全部是真正的像素画。

## 10. 音频
- 音效由脚本合成（挥刀、命中、跳跃、落地、冲刺、破碎）加上太刀和长枪专用音效。
- 设置里可分别调节主音量、音效、武器音量。
- 顿帧时声音照常播放，强调打击瞬间。
- 背景音乐：未制作。

## 11. 设置（Esc 菜单）
主音量、音效音量、武器音量、震屏强度、顿帧开关、全屏。保存在 `user://settings.cfg`，启动时自动读取。
